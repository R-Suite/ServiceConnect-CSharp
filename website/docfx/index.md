# ServiceConnect API Reference

Reference documentation for the ServiceConnect public API, generated from XML doc comments by [DocFX](https://dotnet.github.io/docfx/).

Browse the namespaces and types in the sidebar to the left, or jump straight to the most common entry points:

- `ServiceConnect.Bus` — bootstrap and configure a bus instance
- `ServiceConnect.Interfaces.IBus` — the runtime API for sending, publishing, and request/reply
- `ServiceConnect.Interfaces.IConfiguration` — configuration surface for endpoint, transport, and persistence wiring
